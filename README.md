# Анализ возвратов пользователей Яндекс Афиши

## Описание проекта
Исследование факторов, влияющих на повторные покупки пользователей Яндекс Афиши. 
Анализ сегментов по устройству, типу события, региону, билетному оператору, 
количеству билетов и интервалам между заказами.

## Структура репозитория
- `Итоговый_проект_2_модуль.ipynb` - Jupyter ноутбук с полным анализом
- `requirements.txt` - список используемых библиотек
- `.gitignore` - исключённые из репозитория файлы
- `README.md` - описание проекта

## Основные выводы
- **Устройство:** Desktop-пользователи возвращаются чаще (63.9% против 60.8% у mobile)
- **Тип события:** Выставки (64.4%) и театр (63.3%) удерживают лучше всего
- **Количество билетов:** Оптимум для лояльности — 2-3 билета (73.6% возвратов)
- **Интервал:** Пользователи с 5+ заказами возвращаются в 2 раза быстрее (9.6 vs 21.3 дня)
- **Регионы-лидеры:** Широковская (65.3%), Североярская (64.0%), Шанырский (67.4%)
- **Сервисы-лидеры:** Быстрый кассир (85.2%), Реестр (81.3%), Восьмёрка (68.6%)

## Ключевые инсайты
- Средняя выручка почти одинакова у всех групп (~544 руб.), но распределение кардинально разное
- День недели первой покупки НЕ влияет на вероятность возврата
- Размер региона НЕ гарантирует высокую лояльность
